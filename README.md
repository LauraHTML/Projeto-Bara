# 🌍 Projeto Bará

> O design como ferramenta de transformação social na educação infantil para a construção de práticas antirracistas.

## 📖 Sobre o Projeto

Bará é um projeto que investiga como o design pode atuar como ferramenta de transformação social na educação infantil, com foco na construção de práticas antirracistas. A partir do Pensamento de Design, o projeto propõe uma oficina lúdica aplicada em contexto escolar, convidando crianças e educadores a refletirem sobre identidade, diversidade e convivência desde os primeiros anos de formação.

## 🛠️ Tecnologias Utilizadas

A arquitetura do site foi pensada para garantir alta performance, componentização eficiente e um layout responsivo, garantindo que o visual reflita o cuidado do projeto:

* **[Next.js](https://nextjs.org/)** - Framework React para renderização otimizada (SSR/SSG) e roteamento inteligente.
* **[React](https://reactjs.org/)** - Biblioteca JavaScript para construção da interface de usuário e componentes interativos.
* **[Tailwind CSS](https://tailwindcss.com/)** - Framework de CSS utilitário para uma estilização ágil, mantendo o design system consistente.
* **[Vercel](https://vercel.com/)** - Plataforma de hospedagem utilizada para o deploy contínuo e integração.

## 🚀 Como rodar o projeto localmente

Para contribuir com o código ou rodar o site na sua máquina, siga os passos abaixo:

1. Clone este repositório:

```bash
git clone https://github.com/seu-usuario/projeto-bara.git

```

2. Acesse o diretório do projeto:

```bash
cd projeto-bara

```

3. Instale as dependências:

```bash
npm install
# ou, se preferir usar yarn:
yarn install

```

4. Inicie o servidor de desenvolvimento:

```bash
npm run dev
# ou
yarn dev

```

5. Abra [http://localhost:3000](http://localhost:3000) no seu navegador para visualizar o site.
